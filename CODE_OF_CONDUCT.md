# SessionSifu Code of Conduct

## Our commitment

SessionSifu welcomes users, testers and contributors regardless of experience,
background, identity or ability. We are committed to a respectful environment
where people can report problems, ask questions and improve the project without
harassment or intimidation.

## Expected behavior

- Be kind, patient and specific.
- Critique ideas and code without attacking the person behind them.
- Assume good intent while remaining open to correction.
- Respect different levels of technical experience and accessibility needs.
- Protect private information found in logs, screenshots and session data.
- Accept maintainer decisions gracefully, even when you disagree.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, deliberate
misgendering, doxxing, sustained disruption and personal attacks are not
acceptable. Publishing another person's private information or encouraging
unsafe behavior is also prohibited.

## Scope

This code applies to the repository, issues, pull requests, reviews and other
spaces used to represent SessionSifu. It also applies when someone represents
the project in public.

## Reporting and enforcement

Report conduct concerns privately to the repository owner through their GitHub
profile. Do not include sensitive details in a public issue. Project maintainers
will review reports in good faith, protect the reporter's privacy where
possible and take action proportionate to the behavior.

Possible responses include a private clarification, a warning, removal of
content, temporary participation restrictions or a permanent ban. Maintainers
who are directly involved in a report should not make the final enforcement
decision when another maintainer is available.

## Good-faith project decisions

Rejecting a contribution, closing an issue, requesting technical changes or
enforcing project scope is not by itself a code-of-conduct violation. These
decisions should still be explained respectfully and consistently.
