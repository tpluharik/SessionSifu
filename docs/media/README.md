# Documentation media

`work-continuity-demo.webp`, `work-continuity-demo.mp4` and its poster are
generated by `tools/render-recall-demo.py` from synthetic UI content. The short
walkthrough presents the complete Save · Resume · Find workflow: bounded local
capture, previewable restoration, persistent placement rules, exact-window OCR
search and explicit privacy controls. It records no real desktop or user data.

The older `recall-demo.*` files remain available for release posts that linked
directly to the original Recall-only walkthrough.

The WebP is the lightweight animated README preview. The MP4 is the downloadable
video, encoded as H.264/yuv420p for broad browser compatibility. The PNG is a
static poster and social preview source.

`RELEASE_3.5.27_POSTS.md` contains the current factual release announcement.
The prior `RELEASE_3.5.26_POSTS.md` is retained as release history. Both use
synthetic media and contain no real desktop content or private user data.
