# Documentation media

`recall-demo.webp`, `recall-demo.mp4` and `recall-demo-poster.png` are generated
by `tools/render-recall-demo.py` from synthetic UI content. They demonstrate the
3.2.2 Recall workflow, including the large master-detail preview, per-window
filmstrip and OCR match navigation, without recording a real desktop or user data.

The WebP is the lightweight animated README preview. The MP4 is the downloadable
video, encoded as H.264/yuv420p for broad browser compatibility. The PNG is a
static poster and social preview source.
