# SessionSifu 3.5.27 release posts

Canonical release: <https://github.com/tpluharik/SessionSifu/releases/tag/v3.5.27>

These posts describe tested 3.5.27 behavior. The demo is generated from
synthetic windows and documents and contains no real desktop or user data.

## GitHub release

SessionSifu 3.5.27 brings the product's three work-continuity jobs together:
**Save** a desktop, **Resume** its applications and placement, and **Find** past
context in an optional encrypted local visual timeline.

Portable editions gain persistent app-wide or title-specific window placement
rules, an in-app checksummed release download, and recognition for more browsers
and editors. The release workflow now publishes an SPDX SBOM and build
provenance beside its artifacts. A reproducible synthetic benchmark and a new
Save · Resume · Find demo make performance and behavior easier to verify
without using anyone's private data.

The update preserves SessionSifu's boundaries: Recall stays off by default,
there is no mandatory account or telemetry, portable downloads are not silently
installed, and unsupported compositor placement is reported rather than
overpromised.

Downloads and checksums: <https://github.com/tpluharik/SessionSifu/releases/tag/v3.5.27>
